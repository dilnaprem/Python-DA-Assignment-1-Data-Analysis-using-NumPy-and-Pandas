# Python-DA-Assignment-1-Data-Analysis-using-NumPy-and-Pandas
## About This Assignment

This assignment focuses on learning the basics of data analysis using Python libraries NumPy and Pandas.

## Topics Covered

**1. NumPy**
- Creating 1D and 2D arrays
- Array operations
- Indexing and slicing
- Finding maximum, minimum, and mean values

**2. Pandas Series**
- Creating a Series
- Indexing and filtering
- Updating and removing values
- Calculating CGPA

**3. Pandas DataFrame**
- Creating and exploring DataFrames
- Filtering and grouping data
- Updating values
- Adding and removing rows and columns

## Tools Used

- Python
- NumPy
- Pandas
- Google colab

## Conclusion

Through this assignment, I practiced basic data analysis operations using NumPy and Pandas and learned how to work with arrays, Series, and DataFrames.
